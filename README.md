# Bread Factory｜麦麦面包房

Bread Factory 是一款面向面包爱好者与家庭烘焙者的暖心面包生活小程序。它从“今天吃了什么面包”开始，帮助用户记录味道、管理短保面包，并逐步成长为甜品师和私人面包房主理人。

## 当前版本：v0.3.0

v0.3.0 根据完整产品访谈重新设计了产品骨架，核心从“工厂地图”调整为“面包日历＋会成长的私人面包房”。

### 面包日历

- 打开程序首先看到“今天吃了什么面包”
- 日期中使用面包贴纸展示记录
- 同款显示数量，如 ×3
- 每格最多重叠三张贴纸，其余显示 +N
- 点击日期打开底部抽屉
- 支持拍照打卡、搜索旧记录及从冰箱库存选择

### 冰箱管理

- 所有库存统一按最小份数记录为 pcs
- 支持保存方式、最佳赏味期和建议食用期限
- 临期面包优先提示
- 吃掉后自动扣减库存并生成日历记录
- 支持过期、不喜欢、变质和其他丢弃原因

### 身份递进

- 面包美食家：日历、冰箱和单层橱窗
- 甜品师：解锁食谱、制作台和第二层手作橱窗
- 主理人：解锁现货、想吃申请、订单、配送和评价
- 原型中可通过右上角头像直接切换身份，对比不同阶段功能

### 食谱与制作

- 食谱支持按时间、工具和难度筛选
- AI 入口用于把文字或视频食谱整理成可执行步骤
- 原料按整数克数展示并支持同比例调整
- 制作前逐项勾选原料
- 每一步可拍一张过程照片
- 计时由用户主动开始，并通过奶牛悬浮窗展示
- 跳过或返回步骤时提示失败风险
- 调整成功后可保存为副本，不覆盖原版

### 面包房与橱窗

- 采用“奶油彩铅 × 温暖原木”的 2.5D 房间视觉
- 默认店主角色为小奶牛
- 房间包含冰箱、工作台、橱窗和顾客区域
- 美食家橱窗展示吃过的面包
- 甜品师解锁第二层，展示成功自制成品
- 主理人通过小挂牌管理现货和预订

### 收藏与成长

- 徽章记录首次打卡、成功出炉、食谱改良、订单和好评
- 成就解锁专属家具并获得麦粒积分
- 成就限定装修与麦粒商店装修互不重复
- 第一版不提供积分充值

## 原型能力边界

当前版本用于验证产品结构、视觉方向和关键交互。以下能力仍为前端演示：

- 数据刷新后不会永久保存
- 相机、自动抠图和 AI 食谱解析尚未接入真实服务
- 后台计时、系统通知和微信身份登录尚未接入
- 订单、兑换密码、评价和朋友圈分享为功能骨架
- 装修、角色动作和真实好友关系将在后续版本完善

## 本地运行

需要 Node.js 22.13 或更高版本，并使用 pnpm。运行 pnpm install 和 pnpm dev 后，访问 http://localhost:3000。
