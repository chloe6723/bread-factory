# Bread Factory｜面包时钟

Bread Factory 是一款面向家庭烘焙爱好者的综合面包制作助手。它希望把“找食谱、准备材料、反复查看步骤、单独设置闹钟”的复杂过程，变成一条清晰、可跟随的制作流程。

## 当前版本：v0.2.0

`v0.2.0` 将地图中的核心区域连接为一条可以完整体验的烘焙流程：

> 选择或创建食谱 → 采购原料 → 进入工厂生产线 → 分步制作与计时 → 成品进入面包店 → 发布到 PK 广场

### 地图与田野

- 地图上的区域可直接进入，不再经过二次确认页
- 底部仅保留居中的 `MAP` 按钮，可随时返回地图
- 田野是无任务、无压力的放松空间，自动轮播奶牛与麦田场景
- 保留播种、浇水、收割和面包雨四阶段品牌插画

### 原料市场

- 内置焦糖布丁、云朵戚风、黄油年糕和草莓马卡龙食谱
- “创建食谱”支持粘贴文字或视频链接
- AI 解析原型可生成原料、操作步骤、计时点与烘焙温度
- 选择食谱后逐项勾选原料，全部确认后完成采购

### 我的工厂

- 已采购的食谱自动进入“待开工”生产线
- 支持同时存在多条尚未开工的生产线
- 制作过程采用关卡式步骤推进
- 普通步骤手动确认，发酵、醒发与烘焙步骤自动开启计时流程
- 每一步进入下一关前均可上传照片记录半成品状态
- 最后一步完成后生成产品并送入面包店

### 我的面包店

- 橱窗展示所有成功制作的产品
- 产品支持自定义名称、趣味价格和故事档案
- 产品记录可一键发布到 PK 广场

### PK 广场

- 展示自己发布的成品与制作故事
- 自动生成制作流程海报原型
- 自动组织适合朋友圈的分享文案
- 支持系统分享；不支持时自动复制分享文字

## 当前原型的能力边界

本版本用于验证信息架构和交互闭环，以下能力目前为前端模拟：

- AI 食谱解析尚未连接真实模型
- 食谱、采购、生产线和产品数据刷新页面后不会永久保存
- 图片只在当前浏览器会话中预览，尚未上传云端
- 制作计时器使用短时间演示数据
- 海报为结构化预览，尚未生成真实图片文件
- 微信朋友圈无法由网页直接静默发布，目前使用系统分享或复制文案

## 产品规划

### 食谱

- 接入真实 AI，将文字和视频食谱转换为结构化步骤
- 增加食谱来源、版权、失败风险和实做校准记录
- 收藏、分类和管理待制作食谱

### 生产车间

- 将任务、步骤、计时状态和照片保存到数据库及对象存储
- 增加系统通知、后台计时和意外退出恢复
- 增加暂停、跳过、延长计时和失败分支

### 作品广场

- 按品类分享成功或失败作品并参与投票
- 以制作结果参与食谱投票
- 使用真实照片生成朋友圈文案和制作过程海报

### 个人主页与面包小店

- 喜爱甜品和成功制作徽章
- 作品橱窗与 3D 实物展示设想
- 烘焙故事、趣味价格和作品介绍
- 带作品剪影角标的烘焙日历
- 好友下单、订单管理、快递单号和收货评价
- 可分享的朋友圈作品及订单链接

## 本地运行

需要 Node.js 22.13 或更高版本，并使用 pnpm：

```bash
pnpm install
pnpm dev
```

浏览器访问 `http://localhost:3000`。

## 构建

```bash
pnpm build
```

## 技术栈

- React 19
- TypeScript
- Vinext / Vite
- Tailwind CSS
- shadcn 组件
- Cloudflare D1 数据能力（已预留）
