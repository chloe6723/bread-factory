# Bread Factory｜面包时钟

Bread Factory 是一款面向家庭烘焙爱好者的综合面包制作助手。它希望把“找食谱、准备材料、反复查看步骤、单独设置闹钟”的复杂过程，变成一条清晰、可跟随的制作流程。

## 当前版本

首个原型版本聚焦核心的“生产车间”体验：

- 显示正在制作的面包、当前步骤和预计出炉时间
- 展示距离下一次操作的倒计时
- 逐项核验制作材料
- 提供制作过程拍照记录入口
- 建立食谱、生产车间、作品广场和个人主页四大导航
- 采用适合手机操作的暖色烘焙视觉设计

当前版本属于交互原型。材料核验、任务状态和导航选中状态可操作；食谱详情、拍照上传、作品广场、面包小店及订单系统将在后续版本接入。

## 产品规划

### 食谱

- 内置热门公开烘焙食谱
- 导入文字食谱并自动转换为结构化步骤
- 收藏、分类和管理待制作食谱

### 生产车间

- 开工前材料核验
- 根据食谱自动串联每个制作步骤和计时提醒
- 到点提示下一步操作，避免反复查看食谱
- 每个步骤支持拍照记录

### 作品广场

- 按品类分享成功或失败作品
- 以制作结果参与食谱投票
- 根据作品生成朋友圈趣味文案
- 根据制作照片生成过程海报

### 个人主页与面包小店

- 喜爱甜品和成功制作徽章
- 作品橱窗与 3D 实物展示设想
- 烘焙故事、趣味价格和作品介绍
- 带作品剪影角标的烘焙日历
- 好友下单、订单管理、快递单号和收货评价
- 可分享的朋友圈作品及订单链接

## 本地运行

需要 Node.js 22.13 或更高版本，并使用 pnpm：

```bash
pnpm install
pnpm dev
```

浏览器访问 `http://localhost:3000`。

## 构建

```bash
pnpm build
```

## 技术栈
